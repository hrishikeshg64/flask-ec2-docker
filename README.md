# flask-ec2-docker
A containerized Flask web application built with Docker, hosted on Docker Hub, and deployed on an AWS EC2 instance.

## 🚀 Project Overview

This project demonstrates an end-to-end cloud deployment workflow. It takes a Python Flask web application, packages it into an isolated Docker container, publishes it to Docker Hub, and pulls/runs it on a live AWS EC2 cloud server accessible via the browser.

## 🏗️ Architecture Workflow

Local Flask App ➔ Dockerfile ➔ Docker Hub Image ➔ AWS EC2 Instance ➔ Public Access

---

## 🛠️ Tech Stack

*   **Backend:** Python, Flask
*   **Containerization:** Docker, Docker Hub
*   **Cloud Provider:** AWS (EC2)
